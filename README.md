# 쇼핑몰 프로젝트 


데모: https://hj29cm.netlify.app/

React와 Express를 기반으로 구현한 반응형 쇼핑몰 웹사이트입니다.  
일반 사용자와 관리자를 구분하여 상품, 장바구니, 주문 관리 기능을 구현했습니다.

> 무료 Render 서버를 사용하여 첫 접속 시 데이터 로딩에 약 30초 정도 소요될 수 있습니다.

## 프로젝트 목표
쇼핑몰의 회원, 상품, 장바구니, 주문 흐름을 직접 설계하고 풀스택으로 구현

## User Story 📖
### 사용자
- 이메일과 비밀번호를 이용한 회원가입 및 로그인
- Google 계정 로그인
- 일반 사용자와 관리자 권한 구분

### 상품
- 상품 목록 및 상세 정보 조회
- 상품명 검색
- 사이즈 선택
- 관리자 상품 등록, 수정, 삭제
- 관리자 상품 목록 관리

### 카트
- 상품 추가 및 삭제
- 상품별 수량 변경
- 장바구니 상품 목록과 총 주문 금액 확인

### 주문 및 결제
- 배송 정보 입력 및 주문 생성
- 주문 상품 및 결제 금액 확인
- Toss Payments Widget을 이용한 결제
- 결제 성공/실패 처리 및 결제 승인 검증
- 결제 정보(paymentKey, 결제수단, 결제상태, 승인일시) 저장
- 사용자 주문 내역 조회
- 관리자 주문 및 결제 정보 조회
- 주문 상태 변경 (준비중 / 배송중 / 배송완료 / 환불)

### 좋아요
- 로그인한 사용자의 상품 좋아요 추가 및 해제
- 상품 목록과 상세 페이지에서 좋아요 상태 표시
- 좋아요한 상품 목록 조회
- JWT 인증을 기반으로 사용자별 좋아요 목록 저장 및 관리

## 기술 스택
### FE
* React
* Redux Toolkit
* react-bootstrap
* Tailwind CSS

### BE
* Node.js
* Express
* MongoDB

### Deployment
- 프론트엔드: Netlify에 배포
- 기존 AWS Elastic Beanstalk 배포 서버 종료 후 Render로 재배포
- MongoDB Atlas를 이용한 클라우드 데이터베이스 구성
- 환경변수를 이용해 MongoDB URI와 JWT Secret 관리
- GitHub push 시 자동 배포되도록 구성
